# 👑 Antigravity KingMode + Mission Control

An evolved, full-stack autonomous agent framework for building real software projects with persistent memory, mission orchestration, task tracking, and one-shot execution.

This system transforms a capable LLM into a stateful, self-orchestrating developer agent — complete with phased reasoning, file-based memory, workflow triggers, and strict privacy controls.

## Credits & Inspiration

The structured prompting style and the original "ULTRATHINK" trigger concept were inspired by the public repository:

**AICodeKing** – [yt-tutorial/gemini-king-mode.md](https://github.com/aicodeking/yt-tutorial/blob/main/gemini-king-mode.md)  
YouTube: [@AICodeKing](https://www.youtube.com/@AICodeKing) (117K+ subscribers)

That file provided a strong foundation for disciplined, role-based frontend prompting.

**However, this repository is a complete original evolution:**

- All new phases (Persistent Memory, Execution Engine, Mission Control)
- File-based state management (`.agent/memory.md`, `specs.md`)
- Workflow system with slash commands
- Task checkbox governance
- Privacy enforcement (`.aiexclude`)
- Full-stack architect identity and one-shot delivery rules

Were designed and iteratively optimized independently. No direct content was copied — only the high-discipline prompting approach served as inspiration.

Big thanks to @AICodeKing for sharing powerful prompt techniques with the community!

## Features

- **King Mode Reasoning Engine** – Ultrathink-triggered deep analysis
- **Persistent Memory** – Long-term state via `.agent/memory.md`
- **Mission Control** – `specs.md` as single source of truth with checkbox tasks
- **Workflow Triggers** – `/test`, `/deploy`, extensible
- **One-Shot Execution** – Full implementation, verification, and cleanup
- **Brutalist/Avant-Garde Design System** (optional UI phase)
- **Privacy-First** – Strict `.aiexclude` enforcement

## Getting Started

1. Copy this repo as a template.
2. Fill in `specs.md` with your project objective and tasks.
3. Feed the full `kingmode-master-prompt.md` as your system prompt.
4. Start building — the agent will handle memory sync, task completion, and workflows autonomously.
